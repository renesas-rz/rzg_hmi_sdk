## *RZ/G HMI SDK v3.5.0.0*

{% endif %}

2026/09/03
{: .right .small }

!!! warning "Notice"
	**Issue with HMI SDK v3.5.0.0 Toolchain Installer**

	*Updated: September 18, 2026*
	{: .right .small }

	Depending on the host PC environment, the HMI SDK v3.5.0.0 toolchain installer may fail and terminate with an error.
	In some cases, the installation may appear to complete successfully without any visible errors.
	However, certain internal toolchain configuration updates may not be applied, resulting in an incomplete installation.
	This issue only affects the installation process of the SDK toolchain used to build applications and does not impact the SD card image.  
	To avoid this issue, please use the [HMI SDK v3.5.0.1](https://renesas-rz.github.io/rzg_hmi_sdk/v3.5.0.1/) toolchain installer.
	This issue has been resolved in HMI SDK v3.5.0.1 by incorporating the following upstream openembedded-core fix:

	* [https://git.openembedded.org/openembedded-core/commit/?id=443912d512edbb75f16c52de489b33b6f8687431](https://git.openembedded.org/openembedded-core/commit/?id=443912d512edbb75f16c52de489b33b6f8687431){: target=_blank }

RZ/G HMI SDK version 3.5.0.0 is available. 

- Support for the **RZ/G3L EVK**. <br>
 
- LVGL Update  
    LVGL has been updated from v9.2.2 to v9.5.  
	This update enables GPU-accelerated rendering in LVGL.  
    For more information about LVGL v9.5, please visit:[https://lvgl.io/docs/open/9.5/](https://lvgl.io/docs/open/9.5/)  

- Flutter Update  
    Flutter has been updated from 3.27.1 to 3.38.3.  
    For information about Flutter releases, please visit:[https://docs.flutter.dev/release/release-notes](https://docs.flutter.dev/release/release-notes)

- Linux Kernel Update  
    The previous release (February 2026) was based on Linux kernel 6.1.  
	This release has been updated to Linux kernel 6.12 based on RZ/G3L BSP v1.0.0.  

!!! warning "Notice"
	Please note that HMI SDK v3.5.0.0 supports only the RZ/G3L EVK. Support for the RZ/G3E, RZ/G2L, RZ/G2LC, and RZ/G2UL EVKs, skipped in this release, will be added in v3.4.2.0 (coming soon).
	Until then, use the HMI SDK [v3.4.1.0](https://renesas-rz.github.io/rzg_hmi_sdk/v3.4.1.0/) and [v3.4.0.0](https://renesas-rz.github.io/rzg_hmi_sdk/v3.4.0.0/) for the RZ/G3E, RZ/G2L, RZ/G2LC, and RZ/G2UL EVKs.
