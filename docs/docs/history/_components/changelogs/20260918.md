## *RZ/G HMI SDK v3.5.0.1*

{% endif %}

2026/09/18
{: .right .small }

We would like to announce the availability of RZ/G Linux HMI SDK v3.5.0.1, which addresses an issue and an improvement identified in v3.5.0.0.

In addition to [the updates in v3.5.0.0](https://renesas-rz.github.io/rzg_hmi_sdk/latest/history/#rzg-hmi-sdk-v3500), the following fixes have been made.

 - Cross-toolchain installer fix <br>
   Fixed an issue that could cause installation errors or incomplete toolchain configuration.
    - For more details, please see [here](https://renesas-rz.github.io/rzg_hmi_sdk/v3.5.0.0/#whats-new).
 - LVDS display support <br>
   Updated the LVGL Home Panel Demo for HD resolution (1280 × 720) on the RZ/G3L EVK with an LVDS display.  


!!! warning "Notice"
	Please note that HMI SDK v3.5.0.1 supports only the RZ/G3L EVK. Support for the RZ/G3E, RZ/G2L, RZ/G2LC, and RZ/G2UL EVKs, skipped in this release, will be added in v3.4.2.0 (coming soon).
	Until then, use the HMI SDK [v3.4.1.0](https://renesas-rz.github.io/rzg_hmi_sdk/v3.4.1.0/) and [v3.4.0.0](https://renesas-rz.github.io/rzg_hmi_sdk/v3.4.0.0/) for the RZ/G3E, RZ/G2L, RZ/G2LC, and RZ/G2UL EVKs.
